プライバシーポリシー

本ツールは、運用者が管理権限を持つYouTubeチャンネルの分析データ（再生数、インプレッション、クリック率、視聴維持率など）を、Googleの許可を得て読み取り専用で取得します。

取得したデータは、チャンネル運営者向けのレポート作成と改善提案にのみ使用し、運用者が管理するGoogleスプレッドシートに保存します。第三者への提供・販売は行いません。

本ツールによるGoogle APIから受け取った情報の使用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

許可の取り消しは、Googleアカウントの「サードパーティ製のアプリとサービス」からいつでも行えます。
